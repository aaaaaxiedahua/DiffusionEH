\begin{abstract}
Knowledge graph reasoning infers missing facts by aggregating query-relevant evidence over relational structures. Existing progressive graph neural network reasoners primarily optimize where entity states are propagated, while paying less attention to how query-conditioned relational contexts regulate message formation and how incoming messages interact after converging on the same candidate. We propose RPCD-GNN, a query-conditioned progressive reasoning framework that couples relation propagation with complex-domain message interaction. RPCD-GNN constructs a sparsified weighted relation-co-occurrence graph from relation incidences sharing the same entity and employs a unified query-conditioned relational controller to propagate dynamic relational contexts over this graph. The resulting layer-wise relational context serves as a shared control signal that jointly modulates message content, admission strength, and interaction phase. A complex-domain interaction operator complements direct message accumulation with phase-coherent aggregation, preserving additive support while modeling phase-dependent interactions among messages converging at the same candidate. The fused response recurrently updates candidate states across reasoning layers, connecting dynamic relational control and phase-aware message interaction in an end-to-end process. Experiments on five transductive benchmarks, together with ablation studies, relational-context analysis, phase-coherence analysis, and representative case studies, evaluate the effectiveness and internal behavior of RPCD-GNN.

\section{Introduction}\label{sec:introduction}

Knowledge graphs (KGs) represent real-world facts in the form of relational triples, where entities are connected by semantic relations. Since real-world KGs are usually incomplete, knowledge graph reasoning aims to infer missing or implicit facts from observed graph structures and relation semantics. A typical reasoning query can be formulated as $(h_q,r_q,?)$, where the model is expected to predict the answer entity according to the query entity $h_q$, the query relation $r_q$, and the surrounding evidence in the KG. The key challenge of this task lies not only in reaching candidate entities through multi-hop structures, but also in identifying useful relation compositions and reliable path evidence under a specific query. Accordingly, knowledge graph reasoning plays an important role in many knowledge-driven applications, such as question answering, recommender systems, and drug discovery \citep{Ji2022Survey,Cao2019KGRec,Zeng2022DrugDiscovery}.

Existing approaches broadly fall into embedding-based, path- or rule-based, and graph neural network (GNN)-based paradigms. Embedding methods learn compact triple-level scoring functions, whereas path- and rule-based methods derive predictions from explicit relational compositions \citep{Bordes2013TransE,Trouillon2016ComplEx,Sun2019RotatE,Xiong2017DeepPath,Sadeghian2019DRUM}. Although embedding methods are efficient and explicit paths provide interpretable evidence, neither paradigm directly supports adaptive multi-layer propagation over query-relevant subgraph structures. This motivates GNN-based reasoners, which propagate query-dependent states over relational neighborhoods to support multi-hop inference.

Recent GNN-based reasoners increasingly organize multi-hop inference as query-centered progressive propagation. NBFNet formulates link prediction through generalized Bellman--Ford reasoning, RED-GNN progressively constructs query-dependent relational subgraphs, and AdaProp learns query-adaptive propagation structures \citep{Zhu2021NBFNet,Zhang2022REDGNN,Zhang2023AdaProp}. DiffusionE further reformulates entity-state propagation as a semantics-guided diffusion process, while Top-p reasoning dynamically controls the layer-wise propagation range \citep{Cao2024DiffusionE,Liu2025TopPReasoning}. Within this broad progressive-reasoning paradigm, RPCD-GNN investigates whether query-conditioned relational contexts can jointly regulate message formation and message interaction during recurrent candidate-state updates.

Despite these advances, progressive GNN reasoning remains largely entity-centric. Relation-level graphs and query-conditioned relation representations have been explored in inductive and transfer-oriented reasoning \citep{Geng2023RMPI,Lee2023InGram,Galkin2024ULTRA,Du2026GraphOracle}. However, using a single layer-wise relational context to jointly control message content, admission strength, and interaction phase remains underexplored in transductive progressive reasoning. Meanwhile, conventional aggregators assign weights to individual messages and reduce them additively, without explicitly modeling interactions among messages after they converge on the same candidate. These gaps are closely coupled: relational context governs how each message is formed and admitted, whereas interaction modeling determines how the admitted messages are combined during candidate-state updates. This motivates a unified reasoning process that connects relational context formation, message construction, cross-message interaction, and candidate-state updating.

To address these problems, we propose RPCD-GNN, a query-conditioned progressive reasoning framework that couples a unified relational controller with complex-domain message interaction. RPCD-GNN derives a sparsified weighted relation-co-occurrence graph from relation incidences sharing the same entity. Conditioned on the query relation $r_q$, the controller propagates relation states over this graph to produce layer-wise dynamic relational contexts. These contexts serve as a shared control signal for message content, admission strength, and interaction phase, while the query entity $h_q$ initializes progressive candidate-state propagation. Based on the same context-conditioned gated messages, direct accumulation preserves additive support, whereas phase-coherent aggregation models phase-dependent interactions among messages converging on the same candidate. Their fused response recurrently updates candidate states, connecting dynamic relational control with complex-domain message interaction in a single reasoning process.

The main contributions of this paper are summarized as follows:
\begin{itemize}
\item We propose RPCD-GNN, a query-conditioned progressive reasoning framework that couples a unified relational controller with complex-domain message interaction. The framework integrates dynamic relational-context induction, gated message formation, phase-coherent aggregation, and recurrent candidate-state updates into an end-to-end reasoning process.
\item We develop a unified query-conditioned relational controller over a sparsified weighted relation-co-occurrence graph derived from entity-anchored relation co-occurrence statistics. Crucially, the resulting layer-wise relational context serves as a shared control signal that jointly modulates message content, admission strength, and interaction phase throughout progressive reasoning.
\item We introduce a complex-domain message-interaction operator that complements direct message accumulation with phase-coherent aggregation. By assigning relation-conditioned phases to incoming messages and aggregating their real and imaginary components, the operator exposes pairwise cosine interactions among messages converging at the same candidate entity while preserving their additive support.
\end{itemize}

\section{Related Work}\label{sec:related-work}

\subsection{Embedding- and Path-based Knowledge Graph Reasoning}\label{subsec:embedding-path-reasoning}

Embedding-based methods represent entities and relations in continuous spaces and evaluate candidate triples through parameterized scoring functions. Translational models, represented by TransE and TransR, model relations as transformations between entity embeddings, whereas semantic matching methods such as DistMult and TuckER capture relational compatibility through bilinear or tensor operations \citep{Bordes2013TransE,Lin2015TransR,Yang2015DistMult,Balazevic2019TuckER}. Neural scoring models, including ConvE and InteractE, further enhance feature interactions with convolutional architectures \citep{Dettmers2018ConvE,Vashishth2020InteractE}. These methods provide efficient triple-level prediction but do not explicitly expose the multi-hop evidence supporting a candidate answer.

Path- and rule-based methods instead reason through explicit relational compositions. PTransE incorporates relation paths into representation learning, while Path-RNN, DeepPath, and MINERVA encode or search relational paths between query entities \citep{Lin2015PTransE,Das2017PathRNN,Xiong2017DeepPath,Das2018MINERVA}. DRUM learns differentiable logical rules, whereas PathCon combines relational context with paths connecting an entity pair for relation prediction \citep{Sadeghian2019DRUM,Wang2021PathCon}. These approaches make relational compositions more explicit, but primarily focus on path encoding, path search, or rule induction rather than query-conditioned recurrent propagation over dynamically expanded candidate states.

\subsection{Progressive GNN-based Knowledge Graph Reasoning}\label{subsec:progressive-gnn-reasoning}

Relational GNNs provide the structural basis for multi-hop knowledge graph reasoning. R-GCN applies relation-specific transformations during neighborhood aggregation, whereas CompGCN jointly composes entity and relation representations \citep{Schlichtkrull2018RGCN,Vashishth2020CompGCN}. More recent reasoners organize inference around query-centered progressive propagation. NBFNet formulates link prediction through generalized Bellman--Ford reasoning, RED-GNN recursively encodes query-dependent relational subgraphs, and AdaProp learns query-adaptive propagation structures \citep{Zhu2021NBFNet,Zhang2022REDGNN,Zhang2023AdaProp}. A*Net learns a query-conditioned priority function to explore selected nodes and edges, while DiffusionE interprets progressive entity-state propagation as a semantics-guided diffusion process \citep{Zhu2023AStarNet,Cao2024DiffusionE}. Top-p reasoning further adapts the layer-wise propagation range through multi-layer Top-p message passing \citep{Liu2025TopPReasoning}.

Beyond progressive GNNs, KnowFormer explores structure-aware Transformer attention and relational message passing as an alternative paradigm for knowledge graph reasoning \citep{Liu2024KnowFormer}. Although these methods differ in architecture, they mainly investigate how to organize query-centered propagation, select relevant reasoning structures, and extend the effective receptive field. Within this line, DiffusionE models semantic interactions among the source entity, propagation relation, and query relation within each edge message, while messages arriving at the same target are subsequently aggregated additively. RPCD-GNN advances this line by using layer-wise query-conditioned relational contexts to jointly regulate message formation, admission strength, and phase-aware interactions among co-arriving messages during recurrent candidate-state evolution.

\subsection{Relation-centric Structural Modeling}\label{subsec:relation-centric-modeling}

Relation-centric reasoning methods operate at different structural granularities. ConGLR augments a candidate-specific enclosing subgraph with a heterogeneous context graph for inductive relation prediction, whereas RMPI transforms a candidate-local subgraph into a line-graph-style relation-instance view and performs target-relation-guided message passing for fully inductive reasoning \citep{Lin2022ConGLR,Geng2023RMPI}. These methods construct local relational contexts for individual candidate triples rather than a graph-level topology over relation types.

Other approaches explicitly build graph-level structures among relation types. InGram derives a weighted relation graph from shared-head and shared-tail incidences and uses it to generate representations for entities and relations unseen during training \citep{Lee2023InGram}. ULTRA defines four endpoint-sharing interaction types among relations and marks the query relation to obtain query-conditioned relation representations for a subsequent entity-level GNN \citep{Galkin2024ULTRA}. GraphOracle instead propagates query-conditioned relation states over a directed relation-dependency graph induced by consecutive relation pairs, combined with sequential multi-dataset pre-training and target-graph adaptation \citep{Du2026GraphOracle}.

These studies establish relation graphs and query-conditioned relation representations as prior design choices. RPCD-GNN differs in how relational context is integrated into transductive progressive reasoning. It constructs a fixed sparsified weighted relation-co-occurrence topology from relation incidences sharing the same entity and generates layer-wise query-conditioned relation states over this topology. More importantly, the same dynamic relational context jointly regulates message content, admission strength, and interaction phase. The resulting phase-coherent response is fused with direct additive aggregation before recurrent candidate-state updating, making relational context a shared controller of both message formation and cross-message interaction.

\subsection{Complex-Domain Representations and Message Interaction}\label{subsec:complex-message-interaction}

Complex-domain representations have been widely studied in knowledge graph embedding. ComplEx employs complex bilinear scoring to capture symmetric and asymmetric relations, RotatE represents each relation as an element-wise rotation in the complex plane, and QuatE uses quaternion embeddings and Hamilton products to model richer relational patterns \citep{Trouillon2016ComplEx,Sun2019RotatE,Zhang2019QuatE}. In these approaches, complex or hypercomplex components primarily define entity--relation transformations and triple-scoring geometry.

Complex values have also been introduced into graph neural networks. MagNet constructs a complex Hermitian magnetic Laplacian whose magnitude represents undirected graph structure and whose phase encodes edge direction, enabling complex spectral convolution over directed graphs \citep{Zhang2021MagNet}. Its phase is determined by graph directionality and defines a graph propagation operator, rather than a query-conditioned interaction coordinate among messages arriving at the same knowledge graph candidate.

Attention-based GNNs such as GAT and KBGAT compute edge-wise compatibility scores, normalize them over a neighborhood, and aggregate the corresponding messages through a weighted sum \citep{Velickovic2018GAT,Nathani2019KBGAT}. Neighborhood normalization couples the attention coefficients through competition, but the resulting additive reducer does not explicitly contain pairwise compatibility terms between incoming message values. RPCD-GNN instead assigns a context-dependent phase to each gated message according to the source state, dynamic relational context, and query relation. Phase-coherent aggregation introduces relative-phase-dependent interactions among messages converging on the same candidate and is subsequently fused with direct message accumulation. RPCD-GNN is not a fully complex-valued GNN: its entity states, relation states, recurrent updates, and answer scores remain real-valued, while the real, imaginary, and amplitude components serve as intermediate interaction statistics.

\section{Methodology}\label{sec:methodology}

\subsection{Problem Formulation and Notation}\label{subsec:problem-formulation}

Let $\mathcal{G}_{g}=(\mathcal{E},\mathcal{R},\mathcal{T}_{g})$ denote the observed fact graph available for reasoning, where $\mathcal{E}$, $\mathcal{R}$, and $\mathcal{T}_{g}$ are the entity set, relation set, and observed triple set, respectively. Each triple $(h,r,t)\in\mathcal{T}_{g}$ states that head entity $h$ is connected to tail entity $t$ by relation $r$. Given a query pair $q=(h_q,r_q)$ corresponding to the incomplete triple $(h_q,r_q,?)$, the task is to score all candidate entities and return
\begin{equation}
\hat{t}
=
\arg\max_{e\in\mathcal{E}}
score(h_q,r_q,e).
\label{eq:reasoning-task}
\end{equation}

The main notation used in the model is summarized in Table~\ref{tbl:notations}. The construction of $\mathcal{T}_{g}$ under the training, validation, and test protocols is specified in Section~\ref{subsec:implementation-details}.

\subsection{Model Overview}\label{subsec:overall-framework}

For a query $q=(h_q,r_q)$, the query entity $h_q$ initializes progressive candidate-state evolution, whereas the query relation $r_q$ conditions relation propagation. RPCD-GNN then performs an $L$-layer reasoning process that connects query-conditioned relational context with phase-aware message aggregation. At layer $l$, $\mathbf{h}_{v}^{(l,q)}$ denotes the query-dependent state of entity $v$, and $\widetilde{\mathbf{R}}^{(l,q)}$ denotes the relational context activated by $r_q$.

Each reasoning layer contains three causally connected stages. First, the query relation activates a reusable relation-co-occurrence structure and propagates query-conditioned relational context over it. Second, this shared context jointly conditions the message content, admission gate, and interaction phase of every edge-level message. Third, direct and phase-coherent aggregates derived from the same incoming message set are integrated by a unified aggregation operator to update candidate states. Thus, direct accumulation and phase-dependent interaction provide complementary statistics within one state-evolution process rather than independent prediction branches.

After $L$ layers, the evolved entity states are projected to the global candidate space for answer ranking. Fig.~\ref{fig:framework} gives an overview. Sections~\ref{subsec:relation-codiffusion}--\ref{subsec:model-training} instantiate the three operators and the learning objective. For readability, the query superscript is omitted below when it is unambiguous.

\subsection{Query-Conditioned Relational Context}\label{subsec:relation-codiffusion}

The effective relation identifier space is defined as $\mathcal{R}'=\mathcal{R}\cup\mathcal{R}^{-1}\cup\{r_{\mathrm{id}}\}$. The entity propagation graph is augmented with inverse edges and identity self-loops to support directional and self-preserving message propagation. For the relation-context graph, inverse relation incidences are included according to the reported experimental configuration. RPCD-GNN constructs a sparsified weighted relation-co-occurrence graph $\mathcal{G}_{r}=(\mathcal{R}',\mathcal{E}_{r})$ from recurring local relation co-occurrence patterns in a fixed fact graph. The graph encodes reusable structural associations among relations and is shared across queries, whereas its activations are dynamically conditioned on the query relation at each reasoning layer.

Let $\mathcal{A}_e$ denote the multiset of direction-aware relation incidences at entity $e$ in this fixed graph, where inverse relation types distinguish incoming from outgoing incidences and $n_e(r)$ records the multiplicity of relation $r$. Relation associations are counted between relation types sharing an anchor entity, considering only anchors that contain more than one relation incidence:
\begin{equation}
\begin{aligned}
C_{ij}
&=
\sum_{\substack{e\in\mathcal{E}\\|\mathcal{A}_e|>1}}
n_e(r_i)n_e(r_j),\\
\bar{\pi}_{ij}
&=
\begin{cases}
\dfrac{C_{ij}}{\sum_k C_{ik}},
& \sum_k C_{ik}>0,\\[5pt]
0,
& \text{otherwise}.
\end{cases}
\end{aligned}
\label{eq:relation-structural-prior}
\end{equation}
The normalized co-occurrence associations are filtered by a minimum-weight threshold $\delta_r$, after which Top-$K_r$ sparsification retains the highest-weight structural associations for each receiving relation:
\begin{equation}
\mathcal{S}_{i}
=
\operatorname{TopK}_{K_r}
\left(
\left\{
j\mid j\neq i,\ \bar{\pi}_{ij}\geq\delta_r
\right\};
\bar{\pi}_{ij}
\right).
\label{eq:relation-neighborhood}
\end{equation}
An identity self-loop is included for every effective relation type, so $\mathcal{E}_{r}$ contains the selected pairs $(r_i,r_j)$ with $j\in\mathcal{S}_{i}$ together with $(r_i,r_i)$ for each $r_i\in\mathcal{R}'$. The corresponding edge weight is
\begin{equation}
\omega_{ij}
=
\begin{cases}
1,
& i=j,\\
\bar{\pi}_{ij},
& j\in\mathcal{S}_{i},\ i\neq j.
\end{cases}
\label{eq:relation-edge-weight}
\end{equation}
Here, $\bar{\pi}_{ij}$ is a normalized structural association rather than a deterministic logical transition probability: it reflects how frequently $r_i$ and $r_j$ participate in recurring direction-aware local association patterns, but it does not imply that one relation logically entails the other. Directionality in entity propagation is represented by distinct inverse relation types. Whether inverse incidences participate in relation co-occurrence construction is controlled separately by the relation-context configuration. We use $\mathcal{N}_{r}(i)$ to denote the retained neighbors of receiving relation $r_i$ in $\mathcal{G}_{r}$.

We use $\operatorname{ReLU}(\cdot)$ in relation scoring and in the hidden encoders for message content, admission, and phase assignment. The symbol $\phi(\cdot)$ denotes the dataset-specific post-aggregation activation used in relation-state and candidate-state updates. We use $\operatorname{sigmoid}(\cdot)$ for message admission, $\tanh(\cdot)$ to bound the interaction phase, and $\epsilon>0$ for numerical stability. At entity reasoning layer $l$, query-conditioned relation propagation starts from the layer-specific base relation representations, i.e., $\mathbf{r}_{i}^{(l,0,q)}=\mathbf{r}_{i}^{(l)}$. For inner step $s=1,\ldots,J$ and relation edge $(r_i,r_j)\in\mathcal{E}_{r}$, the query-relation-conditioned activation is
\begin{equation}
\begin{split}
a_{ij}^{(l,s,q)}
={}&
\mathbf{w}_{r}^{\top}\operatorname{ReLU}\bigl(
W_{s}^{r}\mathbf{r}_{i}^{(l,s-1,q)}
+W_{d}^{r}\mathbf{r}_{j}^{(l,s-1,q)}\\
&\quad+W_{q}^{r}\mathbf{r}_{q}^{(l)}
+\mathbf{u}_{\omega}\log(\omega_{ij}+\epsilon)
\bigr).
\end{split}
\label{eq:query-relation-score}
\end{equation}
Under this row-update convention, relation $r_i$ receives a message from relation $r_j$, where $r_j$ supplies the transformed neighbor state. The activations are normalized over the retained neighborhood of the receiving relation $r_i$:
\begin{equation}
\alpha_{ij}^{(l,s,q)}
=
\frac{
\exp\left(a_{ij}^{(l,s,q)}/\tau_r\right)
}{
\sum_{k\in\mathcal{N}_{r}(i)}
\exp\left(a_{ik}^{(l,s,q)}/\tau_r\right)
}.
\label{eq:query-relation-activation}
\end{equation}
The relation state is propagated while retaining the base semantics:
\begin{equation}
\mathbf{r}_{i}^{(l,s,q)}
=
\beta\mathbf{r}_{i}^{(l)}
+
(1-\beta)
\phi\left(
\sum_{j\in\mathcal{N}_{r}(i)}
\alpha_{ij}^{(l,s,q)}
W_{m}^{r}\mathbf{r}_{j}^{(l,s-1,q)}
\right).
\label{eq:relation-state-update}
\end{equation}
After $J$ inner steps, the query-conditioned state is fused with the base relation representation:
\begin{equation}
\tilde{\mathbf{r}}_{i}^{(l,q)}
=
(1-\lambda)\mathbf{r}_{i}^{(l)}
+
\lambda\mathbf{r}_{i}^{(l,J,q)}.
\label{eq:fused-relational-context}
\end{equation}
Here, $\beta$ preserves the base relation semantics throughout inner propagation, while $\lambda$ controls how strongly the resulting query-conditioned context adapts the base relation state.
Thus, the fixed graph contributes a reusable structural substrate, whereas its activation is recomputed for every query relation and reasoning layer. The resulting relational context provides a shared conditioning signal for message content, admission gating, and phase in the subsequent entity-level update. The relation-co-occurrence graph is local in construction but global in use: it is distilled from reusable local relation patterns, while its query-relation-conditioned activations regulate message interaction throughout multi-hop reasoning.

\subsection{Query-Conditioned Message Formation}\label{subsec:entity-diffusion}

Starting from $\mathcal{V}^{(0)}=\{h_q\}$, RPCD-GNN expands the outgoing edges of the layer-wise retained entity set $\mathcal{V}^{(l-1)}$ over $\mathcal{T}_{g}$. The reached entities constitute a provisional set $\overline{\mathcal{V}}^{(l)}$, and the entities reached in the current expansion that are not already retained in $\mathcal{V}^{(l-1)}$ form the candidate set $\mathcal{C}^{(l)}$. An entity discarded at an earlier layer is not permanently excluded and may re-enter if it is reached again in a later expansion. For a provisional target $v$, let $\mathcal{E}_{v}^{(l)}$ denote its incoming expanded edges. The message carried by an edge $(u,r,v)$ is
\begin{equation}
\mathbf{m}_{u,r,v}^{(l)}
=
\operatorname{ReLU}\left(
W_{c}^{m}
\left(
\mathbf{h}_{u}^{(l-1)}
+
\tilde{\mathbf{r}}_{r}^{(l)}
\right)
-
W_{q}^{m}
\left(
\mathbf{h}_{u}^{(l-1)}
+
\mathbf{r}_{q}^{(l)}
\right)
\right).
\label{eq:semantic-evidence-message}
\end{equation}
This contrastive composition measures the compatibility gap between the propagation relation and the query relation in the current source state. Its admission coefficient is
\begin{equation}
\gamma_{u,r,v}^{(l)}
=
\operatorname{sigmoid}\left(
\mathbf{w}_{e}^{\top}
\operatorname{ReLU}\left(
W_{h}^{e}\mathbf{h}_{u}^{(l-1)}
+
W_{r}^{e}\tilde{\mathbf{r}}_{r}^{(l)}
+
W_{q}^{e}\mathbf{r}_{q}^{(l)}
\right)
\right).
\label{eq:evidence-admission-gate}
\end{equation}
The gated message is then
\begin{equation}
\mathbf{x}_{u,r,v}^{(l)}
=
\gamma_{u,r,v}^{(l)}
\mathbf{m}_{u,r,v}^{(l)}.
\label{eq:weighted-relation-evidence}
\end{equation}
Here, $\gamma_{u,r,v}^{(l)}$ controls how much message content is admitted into subsequent interaction. Since $\mathbf{m}_{u,r,v}^{(l)}$ is produced by ReLU and $\gamma_{u,r,v}^{(l)}\in(0,1)$, the gated message $\mathbf{x}_{u,r,v}^{(l)}$ is element-wise nonnegative.

To make the interaction among concurrently arriving messages explicitly learnable, the same source state, relational context, and query relation parameterize a message phase:
\begin{equation}
\begin{split}
\theta_{u,r}^{(l)}
={}&
\pi\tanh\left(
\frac{
\mathbf{w}_{p}^{\top}
\operatorname{ReLU}\left(
W_{p}\left[
\mathbf{h}_{u}^{(l-1)};
\tilde{\mathbf{r}}_{r}^{(l)};
\mathbf{r}_{q}^{(l)}
\right]
\right)
}{
\tau_p
}
\right).
\end{split}
\label{eq:evidence-phase}
\end{equation}
The resulting phase-encoded message is
\begin{equation}
\mathbf{z}_{u,r,v}^{(l)}
=
\mathbf{x}_{u,r,v}^{(l)}
\exp\left(
\mathrm{i}\theta_{u,r}^{(l)}
\right).
\label{eq:complex-relation-phase-evidence}
\end{equation}
Here, $\theta_{u,r}^{(l)}$ is a scalar phase assigned to each edge-level message and broadcast across its hidden dimensions, with $\theta_{u,r}^{(l)}\in(-\pi,\pi)$. The complex notation is used as an intermediate interaction representation; entity states, relation states, recurrent updates, and answer scores remain real-valued.
Equations~\eqref{eq:weighted-relation-evidence} and~\eqref{eq:complex-relation-phase-evidence} show that magnitude and phase are not produced by unrelated components. Both are query-relation-conditioned views of a single message: $\mathbf{x}$ captures its gated content, while $\theta$ specifies how that content interacts with other messages reaching the same candidate.

\subsection{Phase-Aware Message Aggregation}\label{subsec:phase-interference}

\subsubsection{Direct and Phase-Coherent Message Aggregation}

Let $\mathcal{X}_{v}^{(l)}$ collect the gated messages and phases carried by all edges in $\mathcal{E}_{v}^{(l)}$. The direct message aggregate retains the accumulated real-valued message content:
\begin{equation}
\boldsymbol{\mu}_{v}^{(l)}
=
\sum_{(u,r,v)\in\mathcal{E}_{v}^{(l)}}
\mathbf{x}_{u,r,v}^{(l)}.
\label{eq:direct-evidence-moment}
\end{equation}
The phase-coherent message aggregate and its element-wise amplitude are
\begin{equation}
\begin{aligned}
\boldsymbol{\kappa}_{v}^{(l)}
&=
\sum_{(u,r,v)\in\mathcal{E}_{v}^{(l)}}
\mathbf{z}_{u,r,v}^{(l)}
=
\mathbf{M}_{v}^{re,(l)}
+
\mathrm{i}\mathbf{M}_{v}^{im,(l)},\\
\boldsymbol{\rho}_{v}^{(l)}
&=
\left|
\boldsymbol{\kappa}_{v}^{(l)}
\right|
=
\sqrt{
\left(\mathbf{M}_{v}^{re,(l)}\right)^2
+
\left(\mathbf{M}_{v}^{im,(l)}\right)^2
+
\epsilon
}.
\end{aligned}
\label{eq:coherent-evidence-moment}
\end{equation}
All squared, square-root, and absolute-value operations in Eq.~\eqref{eq:coherent-evidence-moment} are applied element-wise.

The mathematical role of phase becomes clear by considering dimension $d$ of the coherent aggregate:
\begin{equation}
\left|
\kappa_{v,d}^{(l)}
\right|^2
=
\sum_i x_{i,d}^{2}
+
2\sum_{i<j}
x_{i,d}x_{j,d}
\cos\left(\theta_i-\theta_j\right).
\label{eq:phase-dependent-interaction}
\end{equation}
The cross terms depend on relative phase. Aligned messages contribute positively to the coherent magnitude, whereas opposing phases can reduce the contribution of their pairwise interaction. Unlike direct additive aggregation, coherent aggregation therefore incorporates phase-dependent interactions without explicitly enumerating message pairs.

The two message aggregates are integrated by a unified phase-aware message aggregation operator:
\begin{equation}
\begin{split}
\mathcal{U}_{\mathrm{RPE}}
\left(\mathcal{X}_{v}^{(l)}\right)
=\;&
\phi\left(
W_{\mu}\boldsymbol{\mu}_{v}^{(l)}
\right)\\
&+
\eta
\phi\left(
W_{re}\operatorname{Re}
\boldsymbol{\kappa}_{v}^{(l)}
+
W_{im}\operatorname{Im}
\boldsymbol{\kappa}_{v}^{(l)}
+
W_{\rho}\boldsymbol{\rho}_{v}^{(l)}
\right).
\end{split}
\label{eq:unified-relation-phase-operator}
\end{equation}
Both aggregates are computed from the same relation-conditioned incoming message set and jointly parameterize a single candidate-state update. The direct aggregate preserves accumulated message content, whereas the coherent aggregate retains phase-dependent interaction structure. Their additive projections therefore represent complementary statistics within one phase-aware message aggregation operator.

\subsubsection{Candidate Retention and Recurrent State Update}

Before recurrent evolution, RPCD-GNN limits the number of newly retained entities to prevent exponential growth of the reasoning set. For each provisional entity $v$, the unified operator output is used as its provisional state $\widehat{\mathbf{h}}_{v}^{(l)}=\mathcal{U}_{\mathrm{RPE}}(\mathcal{X}_{v}^{(l)})$. A candidate is scored by
\begin{equation}
s_{v}^{(l)}
=
\mathbf{w}_{s}^{\top}
\widehat{\mathbf{h}}_{v}^{(l)}.
\label{eq:candidate-selection-score}
\end{equation}
The layer-wise retained entity set is updated by preserving previously retained entities and adding the $K_l$ highest-scoring new candidates:
\begin{equation}
\mathcal{V}^{(l)}
=
\mathcal{V}^{(l-1)}
\cup
\operatorname{TopK}_{K_l}
\left(
\mathcal{C}^{(l)};
\widetilde{\mathbf{s}}^{(l)}
\right).
\label{eq:topk-frontier-update}
\end{equation}
Finally, the message-derived response is accumulated recurrently over reasoning layers:
\begin{equation}
\mathbf{h}_{v}^{(l)}
=
\operatorname{GRU}\left(
\widehat{\mathbf{h}}_{v}^{(l)},
\mathbf{h}_{v}^{(l-1)}
\right),
\quad
v\in\mathcal{V}^{(l)}.
\label{eq:recurrent-entity-update}
\end{equation}
Here, $\widetilde{\mathbf{s}}^{(l)}$ denotes the relaxed candidate-selection scores used during training. To optimize the layer-wise Top-$K_l$ selection, training uses a Gumbel--Softmax relaxation with temperature $\tau$ and a straight-through selection mask, whereas inference performs deterministic Top-$K_l$ selection. Thus, $\mathcal{V}^{(l)}$ is a cumulative layer-wise retained entity set: it contains the previously retained entities together with the highest-scoring newly reached candidates and supplies the source entities expanded at layer $l+1$.

For a newly retained entity, the previous state is initialized to zero. The updated state becomes the source entity state at layer $l+1$, closing the recursive process from relation context to message interaction, candidate retention, and multi-hop state evolution.

\subsection{Answer Prediction and Model Optimization}\label{subsec:model-training}

Algorithm~\ref{alg:rpcd-forward} summarizes the query-level forward process. The fixed relation-co-occurrence structure is activated by the query relation at every reasoning layer.

\begin{algorithm}[t]
\caption{Query-conditioned relation propagation and phase-aware message aggregation in RPCD-GNN}
\label{alg:rpcd-forward}
\begin{algorithmic}[1]
\Require Reasoning graph $\mathcal{T}_{g}$, sparsified relation-co-occurrence graph $\mathcal{G}_{r}$, query $(h_q,r_q,?)$, layers $L$, relation steps $J$, retention budgets $\{K_l\}_{l=1}^{L}$
\Ensure Scores over $\mathcal{E}$
\State Initialize $\mathcal{V}^{(0)}=\{h_q\}$ and its zero state
\For{$l=1$ to $L$}
    \State Initialize $\mathbf{r}_{i}^{(l,0,q)}=\mathbf{r}_{i}^{(l)}$ and propagate $\widetilde{\mathbf{R}}^{(l,q)}$ for $J$ steps
    \State Expand $\mathcal{E}^{(l)}$ and obtain $\overline{\mathcal{V}}^{(l)}$ and $\mathcal{C}^{(l)}$
    \For{each $(u,r,v)\in\mathcal{E}^{(l)}$}
        \State Form gated messages $\mathbf{x}_{u,r,v}^{(l)}$
        \State Assign $\theta_{u,r}^{(l)}$ and form $\mathbf{z}_{u,r,v}^{(l)}$
    \EndFor
    \For{each $v\in\overline{\mathcal{V}}^{(l)}$}
        \State Compute direct and phase-coherent message aggregates
        \State Form provisional state $\widehat{\mathbf{h}}_{v}^{(l)}$
    \EndFor
    \State Score $\mathcal{C}^{(l)}$ and update the retained entity set by Eq.~\eqref{eq:topk-frontier-update}
    \For{each $v\in\mathcal{V}^{(l)}$}
        \State Evolve retained state $\mathbf{h}_{v}^{(l)}$ by Eq.~\eqref{eq:recurrent-entity-update}
    \EndFor
\EndFor
\State Project reached states and map them to the global candidate space
\State \Return $\{score(h_q,r_q,e)\mid e\in\mathcal{E}\}$
\end{algorithmic}
\end{algorithm}

After $L$ reasoning layers, the states of retained entities are projected into the global entity space for answer ranking. For batch element $b$ and entity $e$, define the global representation as
\begin{equation}
\overline{\mathbf{h}}_{b,e}^{(L)}
=
\begin{cases}
\mathbf{h}_{b,e}^{(L)}, & e\in\mathcal{V}_{b}^{(L)},\\
\mathbf{0}, & e\notin\mathcal{V}_{b}^{(L)}.
\end{cases}
\label{eq:global-candidate-representation}
\end{equation}
For each entity $e$, the answer score is then computed as
\begin{equation}
score(h_q,r_q,e)
=
\mathbf{w}_{o}^{\top}
\overline{\mathbf{h}}_{e}^{(L)}.
\label{eq:global-candidate-score}
\end{equation}
The resulting score vector is optimized with a full-entity softmax loss. For each observed training triple $(h_q,r_q,t)$, the observed tail $t$ is used as the target:
\begin{equation}
\mathcal{L}
=
-
\log
\frac{
\exp\left(score(h_q,r_q,t)\right)
}{
\sum_{e\in\mathcal{E}}
\exp\left(score(h_q,r_q,e)\right)
}.
\label{eq:training-objective}
\end{equation}
At evaluation time, all entities are ranked by these scores under the filtered protocol.

\subsection{Computational Complexity}\label{subsec:computational-complexity}

Let $B$ be the query batch size, $d$ the hidden dimension, $a$ the attention dimension, $M_R$ the number of edges in the sparse relation-co-occurrence graph, and $J$ the number of relation-propagation steps within each reasoning layer. Let $M_l$ and $N_l$ denote the numbers of expanded entity edges and reached candidate nodes at layer $l$, respectively, accumulated over the batch. The per-batch online time complexity of RPCD-GNN is
\begin{equation}
\begin{split}
\mathcal{O}\!\Bigg(
\sum_{l=1}^{L}
\Biggl[
{}&BJM_R(d^2+da)
+M_l(d^2+da)
\\
{}&+N_ld^2
+B|\mathcal{E}|\log K_l
\Biggr]
\\
{}&+B|\mathcal{E}|
\Bigg).
\end{split}
\label{eq:computational-complexity}
\end{equation}
The four terms inside the summation correspond, respectively, to query-relation-conditioned relation propagation, entity-edge evidence formation and phase-aware aggregation, recurrent candidate-state updates, and bounded entity retention. The final $B|\mathcal{E}|$ term accounts for assembling the retained states in the global entity space and evaluating the full-entity objective. The dense candidate-space term reflects the current batched implementation: entity propagation is restricted to dynamically reached candidates, whereas candidate selection and global scoring operate over the entity vocabulary. Since each receiving relation retains at most $K_r$ structural associations together with one identity self-loop, the sparse relation-co-occurrence graph satisfies $M_R\leq|\mathcal{R}'|(K_r+1)$. Consequently, the online relation-context overhead is bounded by $\mathcal{O}(BLJ|\mathcal{R}'|(K_r+1)(d^2+da))$, which depends on the relation vocabulary rather than the number of entities once the relation-co-occurrence graph has been precomputed. Before training, the unpruned relation-co-occurrence graph is constructed once in $\mathcal{O}(\sum_{e\in\mathcal{E}}c_e^2)$ time, where $c_e=|\mathcal{A}_e|$ is the number of direction-aware relation incidences at entity $e$, and is subsequently sparsified by relation-wise Top-$K_r$ pruning. Beyond the entity-state tensors required by progressive propagation, the principal additional memory terms are $\mathcal{O}(B|\mathcal{R}'|d+M_R)$ for query-conditioned relation states and the sparse relation-co-occurrence graph.

\section{Experiments}\label{sec:experiments}

\subsection{Datasets}\label{subsec:datasets}

We evaluate RPCD-GNN on five transductive knowledge graph reasoning datasets, including Family, UMLS, WN18RR, NELL-995, and FB15k-237. These datasets span different graph scales and relation vocabularies, allowing us to examine query-conditioned relation propagation and complex-domain message interaction across compact relational benchmarks and larger knowledge graphs.

Family is a relational reasoning dataset derived from kinship relations, where the target is to infer implicit family relations from observed relational facts \citep{Kok2007Statistical,Sadeghian2019DRUM}. UMLS is a biomedical relational dataset constructed from the Unified Medical Language System and is commonly used to evaluate multi-relational reasoning over medical concepts \citep{Bodenreider2004UMLS,Sadeghian2019DRUM}. WN18RR is a leakage-reduced subset of WordNet that removes inverse relations from WN18 to reduce test leakage \citep{Dettmers2018ConvE}. FB15k-237 is derived from Freebase by removing near-duplicate and inverse relations and is a widely used benchmark for link prediction \citep{Toutanova2015Observed,Dettmers2018ConvE}. NELL-995 is a knowledge graph reasoning dataset constructed from the Never-Ending Language Learning project and has the largest entity vocabulary among the five datasets \citep{Xiong2017DeepPath}.

The released benchmark files contain a permanent fact set $\mathcal{T}_{f}$, a training set $\mathcal{T}_{tr}$, a validation set $\mathcal{T}_{va}$, and a test set $\mathcal{T}_{te}$. \subsection{Baselines and Evaluation Metrics}\label{subsec:baselines-metrics}

We compare RPCD-GNN with representative knowledge graph reasoning methods from complementary reasoning paradigms. The non-GNN baselines include embedding-based models ConvE \citep{Dettmers2018ConvE}, QuatE \citep{Zhang2019QuatE}, and RotatE \citep{Sun2019RotatE}; path- and rule-based reasoners MINERVA \citep{Das2018MINERVA}, DRUM \citep{Sadeghian2019DRUM}, RNNLogic \citep{Qu2021RNNLogic}, and RLogic \citep{Cheng2022RLogic}; and parameter-efficient representation models NodePiece \citep{Galkin2022NodePiece} and MorsE with RotatE as its base scoring function \citep{Chen2021MorsE}. Together, they provide comparisons from triple scoring, explicit relational composition, and parameter-efficient representation learning perspectives.

The GNN-based baselines include CompGCN \citep{Vashishth2020CompGCN}, NBFNet \citep{Zhu2021NBFNet}, RED-GNN \citep{Zhang2022REDGNN}, AdaProp \citep{Zhang2023AdaProp}, A*Net \citep{Zhu2023AStarNet}, DiffusionE \citep{Cao2024DiffusionE}, and Top-p reasoning \citep{Liu2025TopPReasoning}. CompGCN represents full-graph relational aggregation, whereas NBFNet, RED-GNN, AdaProp, A*Net, DiffusionE, and Top-p reasoning instantiate different forms of query-dependent progressive propagation. The comparison includes representative reasoning methods whose dataset splits and filtered-ranking protocols are compatible with our setting.

Following the standard filtered-ranking protocol, we evaluate both tail prediction and head prediction, where head-prediction queries are converted into tail-prediction queries using inverse relations. For each query, all entities are ranked according to their prediction scores, while other known correct answers in $\mathcal{T}_{f}\cup\mathcal{T}_{tr}\cup\mathcal{T}_{va}\cup\mathcal{T}_{te}$ are removed only when computing the rank of the target entity. We report mean reciprocal rank (MRR), Hits@1, and Hits@10, with higher values indicating better reasoning performance.

\subsection{Implementation Details}\label{subsec:implementation-details}

At each training epoch $s$, $\mathcal{T}_{f}$ and $\mathcal{T}_{tr}$ are pooled and randomly repartitioned according to the dataset-specific fact ratio $\varrho$. The retained triples form the current reasoning graph $\mathcal{T}_{g}^{(s)}$, while the remaining triples provide supervised queries $\mathcal{T}_{q}^{(s)}$. During validation and testing, $\mathcal{T}_{f}\cup\mathcal{T}_{tr}$ forms the fixed reasoning graph, and queries are drawn from $\mathcal{T}_{va}$ and $\mathcal{T}_{te}$, respectively. The topology and structural weights of the relation-co-occurrence graph are constructed once from $\mathcal{T}_{f}$ and remain fixed throughout training and evaluation, whereas its query-conditioned relational context is recomputed for each query and reasoning layer.

The entity propagation graph is augmented with inverse edges and identity self-loops. For FB15k-237, query-associated one-hop edges are removed from $\mathcal{T}_{g}^{(s)}$ following the transductive protocol used by DiffusionE~\citep{Cao2024DiffusionE}. The inclusion of inverse incidences in the relation-co-occurrence graph follows the reported relation-context configuration.

RPCD-GNN is implemented in PyTorch and optimized using Adam with an exponentially decayed learning rate. The principal backbone, training, relation-propagation, and phase-aggregation settings are reported in Table~\ref{tab:implementation-settings}; values are rounded for readability. The model is trained for at most 300 epochs. RPCD-specific parameters are selected according to validation MRR, and the checkpoint with the highest validation MRR is used for final evaluation. Final results are reported as the mean and standard deviation over three independent runs.

\subsection{Ablation Study}\label{subsec:ablation-study}

To assess how query-conditioned relational context and phase-aware message aggregation affect reasoning performance, we construct two controlled variants of RPCD-GNN. RPCD-GNN w/o relational context disables query-conditioned relation propagation and uses the base relation representations during message formation. \section{Conclusion}\label{sec:conclusion}

In this paper, we proposed RPCD-GNN, a query-conditioned progressive reasoning framework that couples relation propagation with complex-domain message interaction for knowledge graph reasoning. RPCD-GNN connects relation-level structural modeling with cross-message interaction by organizing relational context formation, relation-conditioned message construction, phase-aware message aggregation, and candidate-state evolution within a unified recurrent process. The resulting query-conditioned relational context jointly regulates message content, admission strength, and interaction phase, thereby controlling how messages are formed and combined during candidate prediction.

RPCD-GNN computes a direct message aggregate and a phase-coherent message aggregate from the same set of relation-conditioned incoming messages. Their fused response preserves additive message content while retaining phase-dependent interaction structure among messages converging on the same candidate, and recurrently updates candidate states across reasoning layers.
